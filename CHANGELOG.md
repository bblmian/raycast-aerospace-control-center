# AeroSpace Control Center Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Added a complete visual control center for AeroSpace.
- Added automatic detection for Homebrew and manual AeroSpace installations.
- Added compatibility diagnostics for CLI, app, configuration, and versions.
- Added guided first-run setup with user-confirmed Homebrew or verified official-download installation.
- Added local-versus-latest version checks, optional Homebrew updates, and live installation progress.
- Added recommended and original starter profiles, including floating rules for common chat apps.
- Added adaptive detail layouts and a compact, low-saturation visual hierarchy.
- Added fixed eight-column, keyboard-navigable Grid layouts.
- Replaced decorative multicolor Grid artwork with monochrome, theme-aware 2D template icons.
- Added measured sizing and optical compensation for Raycast's custom-image Grid layout, plus pixel-level regression tests.
- Added a flat blue extension icon with transparent outer corners.
- Added window, workspace, monitor, layout, and service controls.
- Added user-managed Common Shortcuts sourced only from the active AeroSpace configuration.
- Added scheduled pauses from 1–365 days with automatic resume after logout, restart, or sleep.
- Improved AeroSpace upgrades and post-update CLI, application, and version detection.
- Added persistent application rules with automatic configuration backups.
- Added dedicated hotkey-friendly commands and menu bar controls.
